# Website XII DKV 3

## Cara pakai
1. Extract file ZIP.
2. Buka folder di VS Code.
3. Masukkan foto/logo sesuai nama file pada folder `images`.
4. Jalankan dengan Live Server atau buka `index.html`.
5. Untuk GitHub Pages, upload semua isi folder ini ke repository.
